# 🚀 TerboXXX - Premium Digital Services Platform

Современный веб-сайт для цифровых услуг с крутыми анимациями и многоязычной поддержкой.

## ✨ Возможности

- 🎨 **Современный дизайн** - Элегантный хакерский стиль с неоновыми эффектами
- ⚡ **Анимации** - Плавные 3D анимации с Framer Motion
- 🌐 **3 языка** - Азербайджанский, Русский, Английский
- 📱 **Адаптивный** - Полностью мобильная версия
- 🎯 **6 категорий услуг**:
  - 📡 Бесплатный интернет (хосты)
  - 📈 SMM услуги (Telegram, Instagram, TikTok)
  - 🔑 Премиум ключи
  - 🔍 Поиск информации
  - 🔓 Восстановление доступа
  - 🛡️ VPN и безопасность

## 🛠️ Технологии

- **Next.js 14** - React фреймворк
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS** - Утилитарный CSS
- **Framer Motion** - Библиотека анимаций
- **Lucide React** - Иконки

## 📦 Установка

1. **Установите зависимости:**
```bash
cd terboxxx
npm install
```

2. **Запустите сервер разработки:**
```bash
npm run dev
```

3. **Откройте в браузере:**
```
http://localhost:3000
```

## 🔧 Настройка

### Добавление ссылок для оплаты

Откройте файл `src/lib/utils.ts` и измените ссылки для каждой услуги:

```typescript
export const services = [
  {
    id: 'internet',
    link: 'ВАША_ССЫЛКА_ДЛЯ_ИНТЕРНЕТА', // <-- Измените здесь
    // ...
  },
  // ... остальные услуги
];
```

### Изменение цен

В том же файле `src/lib/utils.ts`:

```typescript
{
  id: 'internet',
  price: '5-15', // <-- Измените цену
  currency: 'AZN', // <-- Измените валюту
}
```

### Изменение контактов

Откройте `src/components/sections/Footer.tsx` и измените социальные ссылки:

```typescript
const socialLinks = [
  { icon: Telegram, href: 'https://t.me/ваш_telegram', label: 'Telegram' },
  { icon: Instagram, href: 'https://instagram.com/ваш_аккаунт', label: 'Instagram' },
  // ...
];
```

### Изменение текстов

Все тексты находятся в `src/lib/translations.ts`. Вы можете изменить:
- Заголовки
- Описания услуг
- Цены
- Любые другие тексты

## 🚀 Деплой

### Vercel (Рекомендуется)

1. Создайте аккаунт на [vercel.com](https://vercel.com)
2. Подключите ваш GitHub репозиторий
3. Нажмите "Deploy"
4. Готово! Ваш сайт онлайн

### Netlify

1. Создайте аккаунт на [netlify.com](https://netlify.com)
2. Перетащите папку проекта или подключите GitHub
3. Настройки:
   - Build command: `npm run build`
   - Publish directory: `.next`
4. Deploy

## 🐛 Решение проблем

**Проблема: Анимации не работают**
- Убедитесь, что установлен `framer-motion`: `npm install framer-motion`

**Проблема: Ошибка при сборке**
- Очистите кэш: `rm -rf .next node_modules`
- Переустановите: `npm install`

**Проблема: Языки не переключаются**
- Проверьте localStorage в браузере (может быть заблокирован в приватном режиме)
