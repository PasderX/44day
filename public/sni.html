Инструкция: бесплатный интернет через SNI

Краткий гид по использованию SNI-хостов в популярных приложениях.

01

Найди поддомены

Во вкладке «Поиск» введи домен оператора или популярного сервиса. Программа опросит 9 источников (CT-логи, AlienVault, RapidDNS, Anubis, URLScan, Wayback, CertSpotter + DNS брутфорс) и соберёт максимум поддоменов.

💡 Совет: пробуй azercell.az, bakcell.com, nar.az, m.facebook.com, cloudflare.com, discord.com, zoom.us.

02

Протестируй хосты

Отметь нужные → «Отправить в тест». Программа проверит каждый хост по HTTP/HTTPS, WebSocket, SNI/TLS и оценит Score 0–100.

  • Score ≥ 80 (зелёный): почти точно работает
  • Score 60–79 (cyan): высокий шанс, попадает в ТОП-10
  • Score < 40: не пробуй
03

Углубись в Deep Probe

Нажми DEEP на любом хосте → откроется вкладка с 9 проверками: TLS 1.3, HTTP/2, SNI Routing, Domain Fronting, Replay, ASN, ECH, IPv6, SAN. Хосты с SNI ROUTING + DOMAIN FRONTING — золото для bypass.

💡 В разделе SAN ты увидишь все домены на одном сертификате — это готовые альтернативные SNI на том же IP.

04

Получи готовый Payload

У зелёных строк есть кнопка PAYLOAD — открывает окно с готовыми настройками для:

  • HTTP Injector · HA Tunnel · HTTP Custom · DarkTunnel · TLS Tunnel

Каждое поле копируется отдельной кнопкой. Кнопка «СКОПИРОВАТЬ ВСЁ» копирует только нужные значения (SNI, Port, Mode, Payload) — без лишнего текста.

05

Настрой приложение

Открой нужное приложение → новая конфигурация → вставь скопированные значения:

  • Mode / Connection Type: SSL/TLS (SNI)
  • SNI Host / SNI: поддомен из теста
  • Payload: готовая строка из окна Payload
  • Proxy / Server: ВАШ SSH или V2Ray-сервер (нужно поднять отдельно — например на VPS за $3/мес)
  • Port: 443 (HTTPS) или 22 (SSH)
06

Подключись и тестируй

Жми Connect. Если коннекта нет за 15 секунд — попробуй следующий хост из ТОП-10 (он отсортирован по убыванию шансов). Используй Экспорт → Payloads (.txt) чтобы получить готовые конфиги для всех рабочих хостов сразу.

07

Что нужно знать

  • Программа не может на 100% гарантировать что хост работает у твоего оператора — тестировать нужно вживую
  • Чем больше Score и подтверждений (SNI Routing, Domain Fronting) — тем выше шанс
  • Хосты на Cloudflare / Google / AWS чаще всего в whitelist операторов
  • Нужен свой SSH/V2Ray сервер — без него туннель не построится
Важно: Используйте только в тех сетях, где это разрешено условиями вашего провайдера. Автор не несёт ответственности.
